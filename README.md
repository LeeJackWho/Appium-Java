# Appium-Java

Appium 移动端自动化测试学习仓库（2019），针对真实 APK 的 UI 自动化实战。

## 子项目一览

| 目录 | 被测应用 |
|---|---|
| `Htxq` | 花甜圈 App |
| `IThouse` | IT之家 App |
| `Jiandou` | 简逗 App |
| `Kuaikan` | 快看 App |
| `Qunaer` | 去哪儿 App |

## 技术栈

Java + Appium Java client + TestNG，通过 `com.mooctest`（ Mooctest 测试平台）提交执行。

## 说明

- 用例包含启动配置（desired capabilities）、元素定位与断言的完整流程。
- 测试账号已做占位化处理，运行前请替换为自己的测试账号。
